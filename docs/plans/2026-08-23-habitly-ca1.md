# Habitly CA1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the native Android "Habitly" habit-tracker app satisfying the CA1 rubric (UI/UX, responsiveness, interactive components, meaningful features).

**Architecture:** MVVM — Room persistence → Repository → StateFlow ViewModels → Jetpack Compose (Material 3) UI, Navigation-Compose bottom-nav shell, WorkManager for reminders.

**Tech Stack:** Kotlin, Jetpack Compose, Material 3, Room + KSP, Navigation-Compose, WorkManager, custom Canvas-drawn charts, Robolectric (JVM tests).

**Spec:** `docs/specs/2026-08-23-habitly-ca1-design.md`

## Global Constraints

- Package/applicationId: `com.habitly.app`
- Min SDK 26, Target/Compile SDK 35, Kotlin 2.0.20, AGP 8.5.2
- Fully offline — no network permissions, Room is the only persistence
- Notification permission (`POST_NOTIFICATIONS`) requested at end of onboarding for API 33+
- **No connected emulator/device in this execution environment.** Domain logic and Room/repository
  layers are unit-tested on the JVM via JUnit + Robolectric (`./gradlew testDebugUnitTest` must
  pass with no device). Compose UI screens are written completely and correctly but verified by
  `./gradlew assembleDebug` compiling cleanly plus your own manual run-through in Android Studio —
  do not write instrumented (`androidTest`) UI tests in this plan.
- No placeholders, no `TODO`s — every file is complete, compilable code.
- Robolectric 4.13 (Task 1) only supports up to SDK 34, one below this project's targetSdk 35 —
  `app/src/test/resources/robolectric.properties` with `sdk=34` pins every Robolectric test to
  API 34 globally so no individual test needs an `@Config` annotation. Discovered and fixed while
  executing Task 4; add this file as part of Task 1's scaffold in any future run of this plan.
- `PaddingValues` is `androidx.compose.foundation.layout.PaddingValues` in this Compose BOM
  (2024.09.00) — material3 does not re-export it. Every task snippet that imports it from
  `androidx.compose.material3.PaddingValues` (Task 9's `HabitlyScaffold.kt`/`MainActivity.kt`) is
  wrong; use the foundation.layout import instead. Discovered and fixed while executing Task 9.
- `FilterChip`, `TopAppBar`, and several other Material3 components used across many screens
  (Tasks 12, 14–17) are marked `@ExperimentalMaterial3Api`. Rather than annotate every composable
  that touches one, Task 1's `app/build.gradle.kts` `kotlinOptions` block should add
  `freeCompilerArgs += listOf("-opt-in=androidx.compose.material3.ExperimentalMaterial3Api",
  "-opt-in=androidx.compose.foundation.ExperimentalFoundationApi",
  "-opt-in=kotlinx.coroutines.ExperimentalCoroutinesApi")` — the foundation one covers
  `HorizontalPager`/`rememberPagerState` (Task 10), and the coroutines one silences the
  `runTest`/`advanceUntilIdle` opt-in warning every ViewModel test (Tasks 11+) triggers.
  Discovered and fixed while executing Tasks 12–13.
- `SettingsPrefs`/`OnboardingPrefs` writes go through DataStore's own internal dispatcher, which
  is outside the `TestDispatcher` `advanceUntilIdle()` (Task 11's `MainDispatcherRule`) controls —
  a `SettingsViewModelTest` that calls `viewModel.onThemeModeChange(...)` then immediately
  `advanceUntilIdle()` can read stale state. Since `onThemeModeChange` is a single-expression
  function whose body is `viewModelScope.launch { ... }`, it already returns the launched `Job`;
  the test must call `.join()` on it before asserting, not just `advanceUntilIdle()`. Discovered
  and fixed while executing Task 17.
- Calling `ReminderScheduler.schedule(this)` eagerly from `HabitlyApp.onCreate()` (Task 18)
  breaks WorkManager's default manifest-based auto-initializer under Robolectric — it raced
  `WorkManagerImpl`'s startup and threw `IllegalStateException`, failing **every** Robolectric
  test in the suite (not just reminder tests), since Robolectric instantiates the real
  `HabitlyApp`. Fix: switch to WorkManager's documented on-demand initialization — `HabitlyApp`
  implements `Configuration.Provider` (returning a default `Configuration`), and
  `app/src/main/AndroidManifest.xml` removes the default `androidx.work.WorkManagerInitializer`
  startup entry via `tools:node="remove"` on a merged `androidx.startup.InitializationProvider`
  (requires adding `xmlns:tools="http://schemas.android.com/tools"` to the manifest root, absent
  from Task 1's original manifest). This makes `WorkManager.getInstance()` lazily initialize
  itself from the `Configuration.Provider` on first real use instead of racing app startup.
  Discovered and fixed while executing Task 18.
- Accent seed color: sage green `#6B9080` (per spec §6), used to generate the Material 3 light/dark
  color schemes.

```kotlin
package com.habitly.app.domain

import java.time.LocalDate

object StreakCalculator {

    fun currentStreak(records: List<CompletionRecord>, today: LocalDate): Int {
        val byDate = records.associateBy { it.date }
        var streak = 0
        var day = today
        while (byDate[day]?.completed == true) {
            streak++
            day = day.minusDays(1)
        }
        return streak
    }

    fun bestStreak(records: List<CompletionRecord>): Int {
        val sorted = records.sortedBy { it.date }
        var best = 0
        var running = 0
        var previousDate: LocalDate? = null
        for (record in sorted) {
            val isConsecutive = previousDate != null && record.date == previousDate!!.plusDays(1)
            running = when {
                !record.completed -> 0
                isConsecutive -> running + 1
                else -> 1
            }
            best = maxOf(best, running)
            previousDate = record.date
        }
        return best
    }

    fun completionRate(records: List<CompletionRecord>): Float {
        if (records.isEmpty()) return 0f
        return records.count { it.completed }.toFloat() / records.size
    }
}
```

```kotlin
import java.time.DayOfWeek

object FrequencyValidator {

    fun isValid(type: FrequencyType, specificDays: Set<DayOfWeek>, intervalDays: Int?): Boolean =
        when (type) {
            FrequencyType.DAILY -> true
            FrequencyType.SPECIFIC_DAYS -> specificDays.isNotEmpty()
            FrequencyType.INTERVAL -> (intervalDays ?: 0) > 0
        }

    fun validateName(name: String): Boolean =
        name.isNotBlank() && name.trim().length <= 40
```

```kotlin
package com.habitly.app.domain

enum class AchievementType(val streakThreshold: Int?) {
    FIRST_HABIT(null),
    STREAK_7(7),
    STREAK_30(30),
    STREAK_100(100),
}

object AchievementEvaluator {

    fun evaluate(
        bestStreak: Int,
        isFirstHabitEver: Boolean,
        alreadyUnlocked: Set<AchievementType>,
    ): Set<AchievementType> {
        val newly = mutableSetOf<AchievementType>()

        if (isFirstHabitEver && AchievementType.FIRST_HABIT !in alreadyUnlocked) {
            newly += AchievementType.FIRST_HABIT
        }

        for (type in AchievementType.entries) {
            val threshold = type.streakThreshold ?: continue
            if (bestStreak >= threshold && type !in alreadyUnlocked) {
                newly += type
            }
        }

        return newly
    }
}
```

```kotlin
package com.habitly.app.data.repository

import com.habitly.app.data.local.AchievementDao
import com.habitly.app.data.local.AchievementEntity
import com.habitly.app.data.local.HabitDao
import com.habitly.app.data.local.HabitEntity
import com.habitly.app.data.local.HabitLogDao
import com.habitly.app.data.local.HabitLogEntity
import com.habitly.app.domain.AchievementEvaluator
import com.habitly.app.domain.AchievementType
import com.habitly.app.domain.CompletionRecord
import com.habitly.app.domain.StreakCalculator
import kotlinx.coroutines.flow.Flow
import kotlinx.coroutines.flow.combine
import kotlinx.coroutines.flow.first
import java.time.LocalDate
import java.time.format.DateTimeFormatter

private val ISO = DateTimeFormatter.ISO_LOCAL_DATE

class HabitRepository(
    private val habitDao: HabitDao,
    private val logDao: HabitLogDao,
    private val achievementDao: AchievementDao,
) {

    fun observeHabitsWithStats(today: LocalDate): Flow<List<HabitWithStats>> =
        combine(habitDao.observeActiveHabits(), logDao.observeAllLogs()) { habits, allLogs ->
            val logsByHabit = allLogs.groupBy { it.habitId }
            habits.map { habit ->
                val records = (logsByHabit[habit.id] ?: emptyList()).map {
                    CompletionRecord(LocalDate.parse(it.date, ISO), it.completed)
                }
                val todayLog = logsByHabit[habit.id]?.find { it.date == today.format(ISO) }
                HabitWithStats(
                    habit = habit,
                    currentStreak = StreakCalculator.currentStreak(records, today),
                    bestStreak = StreakCalculator.bestStreak(records),
                    completionRate = StreakCalculator.completionRate(records),
                    isCompletedToday = todayLog?.completed == true,
                )
            }
        }

    suspend fun addHabit(habit: HabitEntity): Long = habitDao.insert(habit)

    suspend fun updateHabit(habit: HabitEntity) = habitDao.update(habit)

    suspend fun deleteHabit(habit: HabitEntity) = habitDao.delete(habit)

    fun observeAchievements(): Flow<List<AchievementEntity>> = achievementDao.observeAll()

    suspend fun toggleCompletion(habitId: Long, date: LocalDate, note: String?): Set<AchievementType> {
        val dateStr = date.format(ISO)
        val existing = logDao.getLog(habitId, dateStr)
        val nowCompleted = existing?.completed != true
        logDao.upsert(
            HabitLogEntity(
                id = existing?.id ?: 0,
                habitId = habitId,
                date = dateStr,
                completed = nowCompleted,
                completedAt = if (nowCompleted) System.currentTimeMillis() else null,
                note = note,
            )
        )

        if (!nowCompleted) return emptySet()

        val allHabitsBefore = habitDao.observeAllHabits().first()
        val isFirstHabitEver = allHabitsBefore.size <= 1 &&
            logDao.observeLogsForHabit(habitId).first().count { it.completed } == 1

        val records = logDao.observeLogsForHabit(habitId).first().map {
            CompletionRecord(LocalDate.parse(it.date, ISO), it.completed)
        }
        val bestStreak = StreakCalculator.bestStreak(records)
        val alreadyUnlocked = achievementDao.observeAll().first()
            .mapNotNull { runCatching { AchievementType.valueOf(it.type) }.getOrNull() }
            .toSet()

        val newlyUnlocked = AchievementEvaluator.evaluate(bestStreak, isFirstHabitEver, alreadyUnlocked)
        newlyUnlocked.forEach { type ->
            achievementDao.insert(AchievementEntity(0, habitId, type.name, System.currentTimeMillis()))
        }
        return newlyUnlocked
    }
}
```

```kotlin
package com.habitly.app.data.seed

import com.habitly.app.data.local.HabitDao
import com.habitly.app.data.repository.HabitRepository
import com.habitly.app.data.local.HabitEntity
import com.habitly.app.domain.FrequencyType
import kotlinx.coroutines.flow.first
import java.time.LocalDate

object SeedDataProvider {

    private data class SeedHabit(val name: String, val icon: String, val colorHex: String, val category: String)

    private val SEED_HABITS = listOf(
        SeedHabit("Drink Water", "water_drop", "#6B9080", "Health"),
        SeedHabit("Read 20 Minutes", "menu_book", "#A4C3B2", "Learning"),
        SeedHabit("Workout", "fitness_center", "#CCE3DE", "Fitness"),
        SeedHabit("Meditate", "self_improvement", "#EAF4F4", "Wellness"),
    )

    // Deterministic pseudo-random pattern per habit index/day offset, avoids java.util.Random
    // (which is fine here, but a fixed pattern keeps the demo data identical across installs).
    private fun shouldComplete(habitIndex: Int, dayOffset: Int): Boolean {
        val pattern = when (habitIndex) {
            0 -> dayOffset % 7 != 3          // strong streak, one weekly miss
            1 -> dayOffset % 2 == 0          // every other day
            2 -> dayOffset < 5 || dayOffset > 10 // broken streak in the middle
            else -> dayOffset % 3 != 0
        }
        return pattern
    }

    suspend fun seedIfEmpty(repository: HabitRepository, habitDao: HabitDao, today: LocalDate) {
        if (habitDao.observeAllHabits().first().isNotEmpty()) return

        SEED_HABITS.forEachIndexed { index, seed ->
```

```kotlin
package com.habitly.app.ui.components

import androidx.compose.foundation.background
import androidx.compose.foundation.layout.Arrangement
import androidx.compose.foundation.layout.Column
import androidx.compose.foundation.layout.Row
import androidx.compose.foundation.layout.size
import androidx.compose.foundation.shape.RoundedCornerShape
import androidx.compose.material3.MaterialTheme
import androidx.compose.runtime.Composable
import androidx.compose.ui.Modifier
import androidx.compose.ui.unit.dp
import com.habitly.app.domain.CompletionRecord
import java.time.YearMonth

@Composable
fun CalendarHeatmap(
    records: List<CompletionRecord>,
    month: YearMonth,
    modifier: Modifier = Modifier,
) {
    val completedDates = records.filter { it.completed }.map { it.date }.toSet()
    val firstDay = month.atDay(1)
    val daysInMonth = month.lengthOfMonth()
    val leadingBlanks = firstDay.dayOfWeek.value % 7 // Monday=1..Sunday=7 -> 0-based blanks from Sunday start

    val cells = buildList {
        repeat(leadingBlanks) { add(null) }
        for (day in 1..daysInMonth) add(month.atDay(day))
    }

    val activeColor = MaterialTheme.colorScheme.primary
    val inactiveColor = MaterialTheme.colorScheme.surfaceVariant

    Column(modifier = modifier) {
        cells.chunked(7).forEach { week ->
            Row(horizontalArrangement = Arrangement.spacedBy(4.dp)) {
                week.forEach { date ->
                    val color = when {
                        date == null -> androidx.compose.ui.graphics.Color.Transparent
                        completedDates.contains(date) -> activeColor
                        else -> inactiveColor
                    }
                    androidx.compose.foundation.layout.Box(
                        modifier = Modifier
                            .size(28.dp)
                            .background(color = color, shape = RoundedCornerShape(6.dp)),
                    )
                }
            }
        }
    }
}
```

```kotlin
package com.habitly.app.ui.home

import androidx.lifecycle.ViewModel
import androidx.lifecycle.viewModelScope
import com.habitly.app.data.repository.HabitDataSource
import kotlinx.coroutines.flow.MutableStateFlow
import kotlinx.coroutines.flow.StateFlow
import kotlinx.coroutines.flow.asStateFlow
import kotlinx.coroutines.launch
import java.time.LocalDate

class HomeViewModel(
    private val repository: HabitDataSource,
    private val today: () -> LocalDate = { LocalDate.now() },
) : ViewModel() {

    private val _uiState = MutableStateFlow(HomeUiState())
    val uiState: StateFlow<HomeUiState> = _uiState.asStateFlow()

    init {
        viewModelScope.launch {
            repository.observeHabitsWithStats(today()).collect { habits ->
                val percent = if (habits.isEmpty()) {
                    0f
                } else {
                    habits.count { it.isCompletedToday }.toFloat() / habits.size
                }
                _uiState.value = HomeUiState(habits = habits, completionPercent = percent, isLoading = false)
            }
        }
    }

    fun onToggleHabit(habitId: Long) {
        viewModelScope.launch {
            repository.toggleCompletion(habitId, today(), null)
        }
    }
}
```

```kotlin
    fun onCategoryChange(category: String) { _uiState.value = _uiState.value.copy(category = category) }
```

```kotlin
package com.habitly.app.ui.allhabits

import com.habitly.app.data.repository.HabitWithStats

data class AllHabitsUiState(
    val allHabits: List<HabitWithStats> = emptyList(),
    val searchQuery: String = "",
    val selectedCategory: String? = null,
) {
    val categories: List<String>
        get() = allHabits.map { it.habit.category }.distinct()

    val filteredHabits: List<HabitWithStats>
        get() = allHabits
            .filter { selectedCategory == null || it.habit.category == selectedCategory }
            .filter { searchQuery.isBlank() || it.habit.name.contains(searchQuery, ignoreCase = true) }
}
```

```kotlin
@Composable
fun BarChart(values: List<Float>, labels: List<String>, modifier: Modifier = Modifier) {
    val maxValue = (values.maxOrNull() ?: 0f).coerceAtLeast(0.01f)
    val barColor = MaterialTheme.colorScheme.primary
    Column(modifier = modifier.fillMaxWidth()) {
        Canvas(modifier = Modifier.fillMaxWidth().height(160.dp)) {

                val barHeight = size.height * (value / maxValue)
                val x = barWidth * (index * 2 + 0.5f)
                drawRect(
                    color = barColor,
                    topLeft = androidx.compose.ui.geometry.Offset(x, size.height - barHeight),
                    size = Size(barWidth, barHeight),
                )
            }
        }
        androidx.compose.foundation.layout.Row(modifier = Modifier.fillMaxWidth()) {
            labels.forEach { label ->
                Text(
                    text = label,
                    style = MaterialTheme.typography.bodyMedium,
                    textAlign = TextAlign.Center,
                    modifier = Modifier.weight(1f),
                )
            }
        }
    }
}
```

```kotlin
@Composable
fun LineChart(values: List<Float>, modifier: Modifier = Modifier) {
    val maxValue = (values.maxOrNull() ?: 0f).coerceAtLeast(0.01f)
    val lineColor = MaterialTheme.colorScheme.primary
    Canvas(modifier = modifier.fillMaxWidth().height(160.dp)) {
        if (values.size < 2) return@Canvas
        val stepX = size.width / (values.size - 1)
        val points = values.mapIndexed { index, value ->
            Offset(x = stepX * index, y = size.height - (size.height * (value / maxValue)))
        }
        for (i in 0 until points.size - 1) {
            drawLine(color = lineColor, start = points[i], end = points[i + 1], strokeWidth = 6f)
        }
```

```kotlin
class CalendarViewModel(private val repository: HabitDataSource) : ViewModel() {

    private val _uiState = MutableStateFlow(CalendarUiState())
    val uiState: StateFlow<CalendarUiState> = _uiState.asStateFlow()

    init {
        viewModelScope.launch {
            repository.observeHabitsWithStats(LocalDate.now())
                .flatMapLatest { habits ->
                    if (habits.isEmpty()) {
                        kotlinx.coroutines.flow.flowOf(emptyList())
                    } else {
                        combine(habits.map { repository.observeRecordsForHabit(it.habit.id) }) { perHabit ->
                            perHabit.toList().flatten()
                                .groupBy { it.date }
                                .map { (date, records) -> CompletionRecord(date, records.any { it.completed }) }
                        }
                    }
                }
                .collect { merged -> _uiState.value = _uiState.value.copy(mergedRecords = merged) }
        }
    }

    fun onMonthChange(month: YearMonth) {
        _uiState.value = _uiState.value.copy(month = month)
    }
}
```

```kotlin
package com.habitly.app.reminder

object ReminderDueChecker {

    fun isDue(
        reminderTime: String?,
        isCompletedToday: Boolean,
        nowHourMinute: Pair<Int, Int>,
        windowMinutes: Int = 15,
    ): Boolean {
        if (reminderTime == null || isCompletedToday) return false
        val (reminderHour, reminderMinute) = reminderTime.split(":").map { it.toInt() }
        val reminderTotalMinutes = reminderHour * 60 + reminderMinute
        val (nowHour, nowMinute) = nowHourMinute
        val nowTotalMinutes = nowHour * 60 + nowMinute
        val delta = nowTotalMinutes - reminderTotalMinutes
        return delta in 0 until windowMinutes
    }
}
```

```kotlin
package com.habitly.app.reminder

import android.content.Context
import androidx.work.CoroutineWorker
import androidx.work.WorkerParameters
import com.habitly.app.data.local.AppDatabase
import com.habitly.app.data.prefs.SettingsPrefs
import com.habitly.app.data.repository.HabitRepository
import kotlinx.coroutines.flow.first
import java.time.LocalDate
import java.time.LocalTime

class ReminderWorker(context: Context, params: WorkerParameters) : CoroutineWorker(context, params) {

    override suspend fun doWork(): Result {
        val prefs = SettingsPrefs(applicationContext)
        if (!prefs.notificationsEnabled.first()) return Result.success()

        val db = AppDatabase.getInstance(applicationContext)
        val repository = HabitRepository(db.habitDao(), db.habitLogDao(), db.achievementDao())
        val habits = repository.observeHabitsWithStats(LocalDate.now()).first()
        val now = LocalTime.now()
        val notificationHelper = NotificationHelper(applicationContext)
        notificationHelper.ensureChannel()

        habits.forEach { habitWithStats ->
            val due = ReminderDueChecker.isDue(
                reminderTime = habitWithStats.habit.reminderTime,
                isCompletedToday = habitWithStats.isCompletedToday,
                nowHourMinute = now.hour to now.minute,
            )
            if (due) {
                notificationHelper.notifyHabitDue(habitWithStats.habit.id, habitWithStats.habit.name)
            }
        }
        return Result.success()
    }
}
```

```kotlin
import com.habitly.app.ui.navigation.Destination
import com.habitly.app.ui.navigation.HabitlyNavHost
import com.habitly.app.ui.navigation.HabitlyScaffold
import com.habitly.app.ui.theme.HabitlyTheme
import androidx.compose.runtime.collectAsState

class MainActivity : ComponentActivity() {
    @OptIn(androidx.compose.material3.windowsizeclass.ExperimentalMaterial3WindowSizeClassApi::class)
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContent {
            val windowSizeClass = calculateWindowSizeClass(this)
            val systemDark = isSystemInDarkTheme()
            val themeMode by remember { SettingsPrefs(this).themeMode }.collectAsState(initial = ThemeMode.SYSTEM)
            val darkTheme = when (themeMode) {
                ThemeMode.DARK -> true
                ThemeMode.LIGHT -> false
                ThemeMode.SYSTEM -> systemDark
            }
            HabitlyTheme(darkTheme = darkTheme) {
                Surface {
                    val navController = rememberNavController()
                    HabitlyScaffold(navController = navController) { padding ->
                        androidx.compose.foundation.layout.Box(modifier = androidx.compose.ui.Modifier.padding(padding)) {
                            HabitlyNavHost(
                                navController = navController,
                                startDestination = Destination.Splash.route,
                                windowWidthSizeClass = windowSizeClass.widthSizeClass,
                            )
                        }
                    }
                }
            }
        }
    }
}
```
